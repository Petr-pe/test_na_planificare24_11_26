# test_na_planificare24_11_26

## Краткое описание

Учебный репозиторий, созданный на уроке по ведению репозитория Git. В нём отработаны создание удалённого репозитория на GitHub, коммиты, ветки, pull request и слияние изменений. Также в репозитории хранятся ссылки на презентацию и интерактивный прототип, сделанные в Figma.

## Цель работы / задачи

**Цель:** освоить базовый рабочий процесс с Git и GitHub и оформить результаты в виде README.

**Задачи:**
- создать удалённый репозиторий на GitHub и связать его с локальным;
- делать коммиты и отправлять изменения на GitHub (`git add`, `git commit`, `git push`);
- создать ветку, внести в неё изменения и оформить pull request;
- слить ветку в основную и разрешить возможные конфликты;
- добавить в репозиторий ссылки на презентацию и прототип в Figma;
- оформить README.md по структуре проекта.

## Инструкции по использованию файлов

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Petr-pe/test_na_planificare24_11_26.git
   cd test_na_planificare24_11_26
   ```
2. Презентацию Figma откройте через файл `ссылка_на_figma_презентацию.url` (двойной щелчок) или по ссылкам из раздела [Figma](#ссылки-на-прототипы-figma).
3. `folder1/lab1.txt` — тестовый файл для упражнений с коммитами и ветками.
4. Чтобы внести изменения: создайте ветку, зафиксируйте правки и откройте pull request:
   ```bash
   git checkout -b my-branch
   git add .
   git commit -m "Описание изменений"
   git push -u origin my-branch
   ```
